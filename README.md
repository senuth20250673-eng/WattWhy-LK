# WattWhy LK

A low-cost home system that shows which appliances use the most
electricity, explains why the monthly bill changed, and forecasts the
next bill using the Sri Lankan tariff blocks.

## The problem
Households receive a bill with total units but no explanation of what
caused them. We want to make that explanation clear and early.

## Planned features
- Whole-home electricity measurement with safe sensors
- Appliance-level estimates
- Bill-change explanation and bill forecast
- Tariff-block warnings
- What-if savings and anomaly alerts
